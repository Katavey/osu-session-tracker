# osu! Session Tracker

**Программа полностью создана с помощью ИИ:** код, интерфейс и сборка подготовлены в процессе вайбкодинга. Автор задавал идеи и требования и тестировал программу. tosu и сторонние иконки созданы их авторами.

Это проект ради прикола для друзей, без больших претензий. Скорее всего, будут обновления.

**Версия 2.1** · [English](README.md) · [Все изменения и установка](RELEASE-NOTES.md)

Трекер сессий для Windows с двумя отдельными сборками: **osu!stable** и **osu!lazer**.

## Скачать и запустить

В [Releases](https://github.com/Katavey/osu-session-tracker/releases/latest) скачай:

- `osu-session-tracker-v2.1-stable-Windows.zip` → `OsuSessionTracker.exe`.
- `osu-session-tracker-v2.1-lazer-Windows.zip` → `OsuSessionTrackerLazer.exe`.

Распакуй архив целиком; папки app и tosu должны оставаться рядом с EXE. Держи версии в разных папках. Автоматический Source code — исходники, а не готовая программа. Требуются Windows 10/11 x64, Windows PowerShell 5.1 и .NET Framework 4.x.

tosu 4.26.2 включён в полные архивы, запускается вместе с трекером и закрывается вместе с последней работающей версией. osu! можно открыть до или после трекера. Если открыты обе игры, tosu следует активному клиенту; независимый одновременный трекинг обеих игр не заявляется.

## Возможности

- Прирост pp профиля, FC, пройденные карты, время, сумма расчётных pp и лучший скор.
- Карточки с фоном карты, рангом, модами, точностью, комбо, попаданиями, прогнозом (if FC … pp) и ссылкой на скор/карту.
- Метки BEST/RECENT и отдельные плитки статистики с медалью FC.
- Архив по дням/месяцам, горизонтальная лента, сортировка, кликабельный лучший скор и экспорт CSV. Текущая сессия продолжает записываться.
- Русский/английский, выбор шрифта, три темы, галерея и свой фон, затемнение, компактные карточки, анимации, маскот, голосовое приветствие и поздравление с топ-5 профиля.
- Скруглённые настройки и предпросмотр оформления; отдельный браузерный предпросмотр OBS с демо-скорами.
- OBS: 0–5 недавних скоров, лучший скор и статистика отдельно, шрифт, три размера карточек, ширина, непрозрачность фона и анимации.

Расчётные pp loved/unranked карт не означают, что столько же добавлено в профиль.

## OBS

«Оформление / OBS» → OBS → выбери параметры → «Применить». Скопируй основной URL, добавь источник «Браузер» и укажи размеры из настроек. Обычный адрес — http://127.0.0.1:24051/ (при занятости до 24059). Не используй временный URL предпросмотра. После обновления обнови источник; старый CSS с !important может переопределять новые настройки.

## Обновление и данные

Для stable 2.0.1: закрой трекер, сделай резервную копию папки и распакуй всё содержимое `stable-UPDATE.zip` поверх неё с заменой. Не ставь stable UPDATE в lazer. Полный архив также можно скопировать поверх соответствующей версии. Настройки, история и свои фоны исключены из релизов и сохраняются:

- `app/settings.json`
- `app/sessions/`
- `app/user-backgrounds/`

Делись оригинальным ZIP релиза, а не своей использованной папкой. Трекер получает локальную телеметрию от tosu; функции профиля могут обращаться к osu! через интернет. EXE не подписан цифровой подписью.
