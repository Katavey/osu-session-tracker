# v2.2.2 — Repeat-play score fix

## English

- Fixed repeated plays of the same map recording the previous result before tosu refreshed its results screen.
- When score, combo and hit judgments match the current play, pp comes from that play rather than cached results-screen pp. Late packets no longer overwrite it with the previous value.
- Includes all v2.2.1 multiplayer and TikTok overlay changes. Available for stable and lazer.

**Update:** close the tracker, back up its folder and extract all contents of the matching UPDATE ZIP over it, replacing files. Settings and history are preserved. Windows ZIPs include tosu 4.26.2 for a fresh installation. Keep editions in separate folders. Previously saved incorrect scores are not recalculated automatically.

This hobby project was fully built with AI; the owner provided ideas and testing. Third-party components belong to their authors. More updates are likely.

## Русский

- Исправлено повторное прохождение одной карты: трекер больше не записывает прошлый результат, пока tosu обновляет экран итогов.
- При совпадении счёта, комбо и попаданий pp берутся из текущего прохождения. Запоздавшие пакеты больше не заменяют их старым значением.
- Все изменения 2.2.1 для мульти и TikTok включены. Обе версии: stable и lazer.

**Обновление:** закрой трекер, сделай резервную копию и распакуй всё содержимое соответствующего UPDATE ZIP поверх папки с заменой файлов. Настройки и история сохраняются. Windows ZIP — полная сборка с tosu 4.26.2. Не смешивай версии. Ранее сохранённые неверные скоры автоматически не пересчитываются.

Проект полностью создан с помощью ИИ; идеи и тестирование — автор. Сторонние компоненты принадлежат их авторам. Дальнейшие обновления вероятны.
